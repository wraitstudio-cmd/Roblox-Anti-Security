# AntiSecurity Core v1.0.0

Roblox Server-Side Security Engine

## [TR] İndirme ve Kurulum
1. İndirme Bağlantısı: [https://github.com/YourUsername/AntiSecurity-Core/releases/latest](https://github.com/wraitstudio-cmd/Roblox-Anti-Security/releases/download/v1.0.0/AntiSecurity.rbxm)
2. İndirdiğin `AntiSecurity.rbxm` dosyasını bilgisayarına kaydet.
3. Roblox Studio'da projeni aç.
4. Dosyayı doğrudan `ServerScriptService` içerisine sürükleyip bırak.
5. Kurulum tamamlandı. Sistem otomatik olarak aktifleşecektir.

## [EN] Download & Installation
1. Download Link: [https://github.com/YourUsername/AntiSecurity-Core/releases/latest](https://github.com/wraitstudio-cmd/Roblox-Anti-Security/releases/download/v1.0.0/AntiSecurity.rbxm)
2. Save the downloaded `AntiSecurity.rbxm` file to your computer.
3. Open your project in Roblox Studio.
4. Drag and drop `AntiSecurity.rbxm` directly into `ServerScriptService`.
5. Installation complete. The system will activate automatically.

## Features / Özellikler
- **Movement Guard:** Speed, Fly, Teleport, Noclip tespiti ve engelleme
- **Network Safety:** RemoteEvent spam sınırlandırması ve hatalı paket filtresi
- **Script Security:** Backdoor, virüs ve yetkisiz zararlı script taraması
- **Data Security:** Leaderstat manipülasyonu ve yetkisiz veri koruması
- **Moderation:** Otomatik Kick, DataStore Ban ve Discord Webhook günlük desteği
